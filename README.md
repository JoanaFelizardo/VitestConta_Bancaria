# Conta Bancária — Programação Orientada a Objetos em TypeScript

Projeto focado na modelagem e implementação de um sistema bancário utilizando os pilares da **Programação Orientada a Objetos (POO)** em **TypeScript**, acompanhado de testes unitários automatizados com **Vitest**.

## Objetivos do Projeto

- Aplicar conceitos de **Encapsulamento**, **Abstração**, **Herança** e **Polimorfismo**.
- Garantir a integridade das regras de negócio (saldos, saques, depósitos e transferências) através de testes automatizados.

## Tecnologias Utilizadas

- **TypeScript**
- **Node.js**
- **Vitest** (testes unitários)
